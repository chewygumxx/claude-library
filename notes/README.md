# notes/

This directory holds the historic record of findings from working with Claude
Code in this repository, one file per session or topic.

## Convention

- Filename: `YYYY-MM-DD-short-topic-slug.md`, for example
  `2026-09-03-notes-directory-convention.md`.
- Date is the date the note was written, not the date of any event it
  describes.
- One topic per file. If a session covers several unrelated topics, split
  them into separate files rather than one combined log.
- Prefer editing an existing file over creating a near duplicate when
  revisiting the same topic later; append a dated subsection instead.
- No fixed internal template is imposed. A short heading and prose or a list
  is sufficient, match whatever form best conveys the finding.

## Scope

Anything worth remembering beyond the current conversation: findings about
Claude Code behaviour, useful commands or configuration discovered, dead ends
already tried, decisions made and why. This is a supplement to `git log` and
commit messages, not a replacement, don't log routine file changes here.
